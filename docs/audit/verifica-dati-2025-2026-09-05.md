# Verifica disponibilità dati INAIL 2025 — 2026-09-05

## Esito: dato 2025 NON ancora integrabile nella serie decennale

Obiettivo: aggiornare la serie decennale 2014-2024 con il 2025 (gap analysis P1).

## Verifiche eseguite (05/09/2026)

| Fonte | Esito |
|---|---|
| CSV semestrali locali (`data/raw/semestrale-*.zip`) | Solo 2020-2024 (verificato conteggio record per anno su Lombardia e Lazio) |
| CSV semestrale scaricato oggi dal portale (`dati.inail.it/opendata/downloads/daticoncadenzasemestraleinfortuni/zip/...`) | Identico al locale: 574.299 record Lombardia, fermo al 2024. Il portale non ha ancora pubblicato il semestrale con il 2025 |
| API mensile `DatiConCadenzaMensileInfortuni` | Gen-Giu 2025 OK; **Lug-Dic 2025: HTTP 500** (fuori finestra di esposizione) |
| API semestrale `DatiConCadenzaSemestraleInfortuni` | 2025: HTTP 500 (non ancora esposto) |
| Endpoint annuale | Non esiste (404) |
| Comunicato INAIL dicembre 2025 (feb 2026) | 416.900 denunce occasione di lavoro 2025, +0,5% vs 2024 (414.853). **Perimetro diverso**: solo occasione di lavoro, al netto studenti, contro il totale lavoro+itinere tutte le gestioni della serie (2024 = 593.627) |

## Decisione

**Non integrare il 2025 nella serie decennale adesso.** Il dato da comunicato ha un
perimetro non confrontabile con il resto della serie (violerebbe RULES.md: stessa cifra
= stessa fonte, perimetro dichiarato, trend leggibile). Aggiungere un punto con perimetro
diverso produrrebbe un falso trend.

## Quando aggiornare

- Appena INAIL pubblica il semestrale con il 2025 (controllo periodico: stesso URL dei
  CSV semestrali, o API semestrale).
- Il congiunturale pari perimetro (I semestre 2025 vs 2026) resta valido e separato:
  usa i dati mensili Gen-Giu, perimetro dichiarato in pagina.

## Azione registrata

- Gap analysis aggiornata: candidato "serie decennale con 2025" → stato **bloccato
  temporaneamente** (fonte non pubblicata), non chiuso.
- Da ricontrollare al prossimo ciclo di aggiornamento dati (cron o sessione).
